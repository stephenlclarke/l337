## Failure, cold Continue and owners

Actual target destruction fails unpaid and retains the original held or installed state. After target loss, genuine later cargo loss or an unpaid source return can retire the held batch without rewriting the existing failed completion. An installed regulator survives player hull loss. Completed payment and clue survive later station destruction. Earlier material use never restores stock. Continue retains exact native lifecycle, original materials, route, socket, engineer inspection and terminal in closed Normal 57/Alien 58 and the current composite envelope through G12. The independent core inquiry can recover only the missing clue.
