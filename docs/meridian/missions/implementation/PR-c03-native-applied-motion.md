# Add the native C03 applied-motion branch

## Resulting behavior

C03 can distinguish actual native motion from its legacy camera/powered phase. A mutation-issued segment is recorded only after native retention publishes the real endpoint. The native sealer requires every segment to be one of the private clock owner's exact accepted legs, with a continuous flight/body/celestial chain. It also retains the existing actual-frame, original-life, geometry, inventory, event and unchanged-scene requirements.

The inspection consumer can read endpoints from either sealed record. It still requires both actual seal queries, original captain consent and all unchanged original-source joins. Neither record certifies continuous ray visibility or permits a decoded receipt to issue evidence.

## Implementation

- Add `NativeC03NewtAppliedSegment` with a file-private constructor at the actual native retention boundary. No construction occurs in the predicted path mutator or planner.
- Add a separate `recordedNative` record and native sealer. Preserve the legacy record, original positive tests and hard scene gates.
- Join native route preparation to the real installed source. Project the same world waypoint into the selected post-camera planning frame without treating that projection as applied motion. Suppress generic arrivals for recognized originals.
- Replace the borrowed-Commander register-recovery `map` with an ordered optional branch. The same predicates run at the same lazy guard position; no whole Commander copy is introduced. The same bounded check found four older borrowed-state captures in laboratory/register/wake validation; these become ordered loops at the same guard positions. New native route helpers read only the body ID at their original guard point rather than capture a borrowed body. Borrowing and short-circuit order remain intact without whole Commander or state copies.
- Add five tests using real original commissioning and actual native interval owners. They cover inert preparation, actual accepted chronology, omitted/replayed/mismatched capture chains, missing clock and invalidated route. No test fabricates an actor, hardware grant, clock witness or outer frame counter.
