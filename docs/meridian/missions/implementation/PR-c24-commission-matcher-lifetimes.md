The original pack matcher now calls separate identity and declaration functions with borrowed parameters and explicit compiler boundaries. Identity checking returns before the hash calls. Declaration projection begins after they return. The native Under Tow command validator also borrows its pack. Every original predicate and both byte hashes remain required.
