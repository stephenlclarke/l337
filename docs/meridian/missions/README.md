# Meridian mission walkthroughs

This is the checklist for the 64 original clue-bearing missions, in catalogue order. A walkthrough is checked after its design, story, current configuration and physical requirements have been reconciled. Open source dependencies and native acceptance remain separate from that check. The Unwritten Route finale is a separate consumer of the 64 clues.

Read the [illustrated intended story](../INTENDED-GAME-STORY-WALKTHROUGH.md) alongside each mission. The authored archive at `c70110b292077588a0855fb48127adfb1b611c9d` holds `docs/meridian/missions/definitions/`, the original campaign prose and associated gameplay data. Current `main` holds the story and assets in `docs/meridian/`, current mission gameplay and implementation notes here, actual executable content in `Sources/L337Core/Resources/` and work ownership in the [main completion ledger](https://github.com/stephenlclarke/l337/blob/main/docs/COMPLETION-LEDGER.md). Walkthroughs link exact source without restoring historical copies as a second canon.

**Progress:** 64 of 64 walked through. Full in-game acceptance on the current build remains open for all 64 missions.
