# Preserve an actual MAIN dispatch through missing-content cold resume

## Problem

The maintained original mission resume writer test follows the separate earned Okapi acquisition, captured-person care, paid navigation and flown Salamander route before accepting a package. That remains a useful owning case. It does not independently cover an already accepted MAIN dispatch saved without its pack, then resumed from a new runtime after exact content restoration. MAIN uses the existing calibrated starter and its actual swept main-station source, so this path needs no new ship or mission-role admission.

The acceptance and decline owning tests do not establish that losing mission content across an app restart retains the original package, active reservation and history. Installing the pack must not itself clear suspension, duplicate acceptance, consume cargo or grant progress. A missing pack or missing writer must refuse resume. A failed real publication must retain the suspended commander and every previous save file; retry must clear only suspension.

## Scope and required result

Add one source-authored owning test in ScriptOriginalMainMissionResumeTests.swift. Reuse the existing MAIN fixture for actual docking, board generation, native confirmation, current writing and unavailable-content suspension. Save while content is unavailable, independently cold load that save, refuse missing-content resume, install the exact bundled pack, refuse an unbound writer and a blocked actual writer, then retry and independently cold load again. Require full commander equality, world preservation on refusals, exact original package/job/history, unchanged active-service count, current saved state, read-only locked/active gallery projection and a semantically idempotent successful resume. Successful repeat resume may publish a fresh save generation; read the new current pointer with ScriptSaveStore.read and require durable commander/world equality and world consistency. Exact save-file byte equality remains required for refusals and read-only cold/gallery operations.

Preserve the existing Salamander/earned-hull test and every production/helper file. No source, ship, person, station, cargo, clue, reward, event or receiving receipt is manufactured. Expected value copies are comparison assertions only. This is one current original mission regression, not a new compatibility reader, migration, pack format or runtime API.
