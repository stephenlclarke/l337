# Extract pure outer-frame motion from existing native kernels

## Change

Provide immutable NPC steering/translation and mission-shot lifetime/grace/movement results. The current native call sites reuse the extracted formulas while retaining their existing source validation and effects. A copied-state ordnance planner reuses the actual private native move algorithm, including the seeker's existing one-over-120-second guidance intervals, finite propulsion range and lifetime. It never receives ECM, damages a target, changes a body, advances a real clock, projects an event or removes anything. No completed Game is produced or copied into a cut.

This is source preparation in isolated TMP only. It does not replace Game.tick, authorize live actor motion, accept a source or constitute a complete once-only runtime split. The current kernels remain unchanged in effect ownership; their source hunk changes only share math. Full NPC pure preparation needs the exact clinic owner seam identified in the issue.

Never re-rotate or translate an already prepared path twice. Ordnance positions/velocities are already canonical.
2. New actors exist only from their real birth time. Existing shot movement uses the passed delta, while ordnance uses lastUpdatedAt. Apply the pure availableDelta window using actual archive emission time; a shot born by T1 gun firing must not move or hit before T1. Keep actual retained shot.age as the lifetime/grace input; do not reconstruct its age from historical emission time after a current outside-bubble suspension. A stale ordnance cursor fails preparation. No backward-dated body, synthesized identity, assigned source role or restored old actor substitutes for the actual opening.
3. Keep live geometry and native contact authority with G1/G3. A prepared trajectory is not a NativeMissionImpactProof or NativeMissionOrdnanceImpactProof. The existing sealed producer must rejoin actual shot/ordnance identity, retained source, scene revision, epoch/clock, muzzle policy and current collision contact. An intervening real contact truncates that trajectory; it does not authorize its planned future endpoint.
4. Move/age each accepted projectile leg once. Commit the actual first hit once, then its damage/law/event projection and termination once. Without contact, commit expiry/removal once at its actual finite boundary. Do not run stepMissionNativeProjectile after already applying its prepared full displacement: the existing routine starts its delta sweep at the live position and would move twice. Extract the native commit around the existing proof/impact/removal code, preserving all proof validation and native event-capacity rollback.
5. Preserve ordnance receiveECM order, unique activation resistance, muzzle clearance, range-versus-inherited-velocity accounting, target loss, safe-gunnery observer and finishEmission behavior. Pure motion does none of them. Resolve actual active fields once at the appropriate existing owner boundary, invalidate an ended trajectory, and never promote a copied proposed termination directly into a live native effect without the owner join. 6. Once per actual outer result, apply the existing NPC recharge/status changes and arrival/lost events, transit-spool refusal state, clinic control proof and coupled clinic/Ark/transit acceptance. Preserve original source conditions and body order where effects depend on it. Do not stamp future status, attempts, retry calendar or dock/arrival state into early cuts. The existing post-motion resolvers must consume the actual retained endpoints, not an unaccepted final proposal. G1 determines the exact phase with the original C01 witness and native-clock rules.
7. G1 retains one outer weapon cooling/aim/firing pass and current allocator order. T1 births are added only then. Contact/termination can suppress later fire or motion through existing guards; a frozen motion proposal must not resurrect a destroyed actor, target or emitter. No new authority factory or generic callback can bypass those checks.

## Meaningful source-authored checks

- NPC cuts sample one already prepared semi-implicit acceleration decision; no repeated acceleration per cut. Out-of-window samples refuse.
- A shot's collision delay excludes its initial inactive interval, and its actual lifetime limits both movement and query range. T0, interior and T1 emissions get only their available interval; future/invalid clocks refuse.
- Three existing ordnance profiles prepare unchanged live commander/bodies/world and retain original muzzle/ECM state. A detached call to the existing native kernel supplies the motion control, with the same distant target and actual source clock. Seeker guidance steps retain the existing bound.
- Actual emission time prevents earlier samples. A stale cursor refuses. Lost-target and finite-expiry proposals leave live body/law/allocator/removal state untouched.
- G1 must additionally qualify actual per-cut moving contact, an interior birth, T1 weapon birth, actual first-hit once-only law/event/projection, finite expiry, ECM, event-capacity refusal and no-effect replay. Existing GameplayOrdnanceTests, MissionNativeBridgeTests and ScriptNPCTests retain their positive/negative facts. The new arithmetic tests do not prove those runtime joins.
