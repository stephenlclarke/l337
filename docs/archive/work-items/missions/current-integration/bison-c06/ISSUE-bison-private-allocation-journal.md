# Bind Bison reservations to one actual allocator and retained root

The previous unpublished nil-owner candidate factory could issue unrelated private identities for repeated calls. It did not establish a retained allocation owner. The replacement reserves through the actual native actor allocator and stores the journal in the proposed canonical Commander field. Callers cannot supply nil or a replacement journal to the reservation API. Creation of unit identities remains private to the same source file and follows actual allocation inside a copied Game candidate.

Exact request reentry returns the same actor, owner and thirteen unit identities, including after another actor allocation or a clock advance. Conflicting request data, stale context, existing actor/spawn aliases, malformed current wire, foreign Commander ownership and invalid allocator bounds refuse without changing the real allocator or journal. A second independent request allocates one different actor and disjoint unit identities. The journal retains only logical reservations and UNOBSERVED physical fields.

Actual physical commissioning is still unavailable. The actual admission hook preserves all existing qualified preflight. If that preflight ever permits reservation, a commissioning refusal retains only the logical reservation. Journal version 1 always bars publication and has no completed-state transition. It creates no body, person, hardware, pressure, temperature, charge, service origin or operative flag.

The proposed Commander field, Codable key, equality and validation changes are exact unapplied shared-root patches for G1. The owner and tests now depend on those patches; this complete proposed composition is UNCOMPILED and UNRUN. No maintained G1 Game, clock or save-root file is changed. Whole-Game cold acceptance remains pending: G1 must bind its actual load/save entry points, expected journal presence, scene/custody and durable write/rollback handling, then run and review the result. Optional absence in an old root is not evidence that a formerly retained journal may be dropped from a current save.

The thermal, gas/test, capacity, finite observed-store and complete-issue service-origin blockers from the parent remain with G4 and the actual physical owner. Allocation clock is never service origin. This child grants no qualified birth and does not change current SH029 or default M01.
