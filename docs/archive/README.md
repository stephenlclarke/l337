# Documentation archive

Historical checkpoints and research retain their source and acceptance context. ISSUE/PR topic folders now hold only [outstanding or unresolved work records](../milestones/WORK-ITEMS.md), not finished work. The human’s current rule removes fixed and integrated ISSUE/PR Markdown, including archive duplicates; their original bytes remain in Git history. Current requirements and separate unresolved acceptance stay visible in the ledger/contracts.

Retained matching issue/PR subjects stay together in the existing topic folders. Each topic index states outstanding/unresolved status explicitly. Finished integrated subjects have no archive copy.
