# Current Newt kit save boundary

The finite current escape kit carries an original hardware identity, birth actor and person, consumed stock, actuation state and release receipt. Existing save envelopes predate these fields. Synthesized optional decoding can discard misplaced keys or collapse explicit null into absence. Generic raw commander input also lacks the current world and custody joins required by this equipment.

The current format must preserve the exact stock and receipt wherever they actually reside. This includes ordinary NPC snapshots, original EMP custody, retained EMP hulls and pods, and the current world. A rescued pod remains in the EMP archive after its live binding is removed. Save selection must therefore consider retained objects regardless of their live bindings or NPC terminal status.
